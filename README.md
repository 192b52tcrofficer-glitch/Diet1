# 輕盈日記：綜合減重 App

一個不用安裝、打開瀏覽器就能用的減重 App（PWA，可「加入主畫面」當手機 App 用，支援離線）。所有資料只存在你自己的裝置上。

## 功能

| 分頁 | 內容 |
| --- | --- |
| 🏠 今日 | 熱量環（目標 − 攝取 + 運動 = 剩餘）、蛋白質／碳水／脂肪進度、各餐熱量、喝水杯數、斷食狀態、每日減重小知識 |
| 🍱 飲食 | 早／午／晚餐＋點心紀錄，內建近 50 種台灣常見食物（便當、珍奶、雞排、超商食物…），可建立自訂食物、調整份數 |
| 🏃 運動 | 16 種運動，依 MET × 體重 × 時間計算消耗，消耗會加回當日熱量額度 |
| ⚖️ 體重 | 每日體重、BMI（國健署分級）、目標完成度、體重折線圖＋7 日平均、依最近趨勢預估達標日期，減太快會提醒 |
| ⏱️ 斷食 | 12:12、14:10、16:8、18:6、20:4、OMAD 方案，即時計時、身體階段提示、歷史與達標統計 |
| ⚙️ 設定 | 個人資料 → 自動算出 BMR、TDEE、每日熱量目標與營養素目標；匯出／匯入備份 |

### 計算方式

- **BMR**：Mifflin-St Jeor 公式
- **TDEE**：BMR × 活動係數（1.2 – 1.9）
- **每日熱量目標**：TDEE − 每週減重量 × 7700 ÷ 7，最低不低於 1200（女）／1500（男）kcal
- **營養素**：蛋白質 1.6 g × 目標體重，脂肪佔 25% 熱量，其餘為碳水
- **喝水目標**：體重 × 35 ml
- 熱量目標會隨最新體重自動調整

## 使用方式

```bash
npm start        # 啟動本機伺服器，打開 http://localhost:8080
npm test         # 執行計算函式的單元測試
```

也可以直接把整個資料夾部署到 GitHub Pages、Netlify 等靜態網站空間。

## 專案結構

```
index.html        頁面骨架與底部分頁
css/styles.css    樣式（支援深色模式、手機版面）
js/calc.js        BMR/TDEE/BMI/營養素/趨勢預估等純計算函式
js/data.js        食物、運動、斷食方案資料
js/app.js         畫面渲染、互動與 localStorage 儲存
sw.js             離線快取
test/             單元測試
```

> 本 App 數值皆為估算，不能取代醫師或營養師的專業建議。
