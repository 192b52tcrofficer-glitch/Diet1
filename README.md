# 輕盈日記：綜合減重 App

依照「靠 iPhone 與 Apple Watch 3 個月瘦 7 公斤」影片的方法打造。影片用了 6 個 App，這裡整合成一個網頁 App。不用安裝，打開瀏覽器就能用（PWA，可「加入主畫面」，也能離線使用）。資料只存在你自己的裝置上。

## 核心邏輯

- **熱量赤字**：每日消耗（TDEE）大於每日攝取。飲食佔減重成敗 70–80%，運動佔 20–30%。
- **降低記錄阻力**：拍照、一鍵記錄、自動倒數，把「記錄、監測、提醒」縮短成幾秒鐘。
- **看趨勢、不焦慮**：AI 與 App 估算都有 10–20% 誤差，重點是長期趨勢。

### 網頁版做不到的部分

Apple Watch 錶面複雜功能、iOS「即時動態」和 Apple「健康」的心率與睡眠資料，都需要原生 iOS App 才能存取，網頁無法使用。替代做法：
- 斷食倒數和喝水按鈕放在「今日」頁最上方，加入主畫面後打開就能看到、一點就記錄。
- 體重用 CSV 匯入；咖啡因用你選的半衰期估算對睡眠的影響。

## 計算方式

- **BMR**：Mifflin-St Jeor 公式
- **TDEE**：BMR × 活動係數（1.2–1.9）
- **每日熱量上限**：TDEE − 每週減重量 × 7700 ÷ 7。女性最低 1200 kcal，男性最低 1500 kcal
- **營養素**：蛋白質 1.6 g × 目標體重，脂肪佔 25% 熱量，其餘為碳水
- **咖啡因**：每份依 `mg × 0.5^(經過小時 / 半衰期)` 衰減後加總。每日上限 400 mg，體重較輕者以 6 mg/kg 為上限
- **訓練負荷**：session-RPE（自覺強度 × 分鐘），近 7 天平均 ÷ 近 28 天平均。比值 0.8–1.3 為適中；資料不足 3 週時只顯示「累積中」

## 拍照估算怎麼用

1. 按「📷 拍照估算」，填補充說明（選填），按「📋 複製提示詞」。
2. 打開 ChatGPT（或 Gemini、Claude 等任何 AI），貼上提示詞並附上餐點照片送出。
3. 把 AI 的回覆整段複製，貼回 App 按「解析回覆」，確認數字後加入紀錄。

iPhone 上也可以按「🖼️ 選照片」，用分享選單把照片＋提示詞一次傳到 ChatGPT App。

App 本身完全不連網路、不需要任何帳號或 API 金鑰，所有資料只存在你的手機裡。

## 在 iPhone 上像 App 一樣使用

### 第一步：把 App 放到網路上（只需做一次）

iPhone 要透過 HTTPS 網址才能「加入主畫面」並離線使用。選一種方式：

**方式 A：GitHub Pages（免費，推薦）**
1. 把這個分支合併到 `main`。
2. 因為免費帳號的 GitHub Pages 只支援公開 repo，請到 repo 的 **Settings → General → Danger Zone → Change visibility** 改成 Public。程式碼裡沒有任何密碼或個人資料；你的飲食、體重紀錄只存在手機上，不會公開。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等 1–2 分鐘，網址會是 `https://<你的帳號>.github.io/Diet1/`。

**方式 B：Netlify Drop（repo 維持私人）**
1. 在電腦上下載這個 repo 的 ZIP 並解壓縮。
2. 打開 https://app.netlify.com/drop ，把資料夾拖進去，會得到一個 `https://xxx.netlify.app` 網址（註冊免費帳號可以保留網址）。

### 第二步：加入 iPhone 主畫面

1. 用 **Safari** 打開上面的網址（一定要用 Safari）。
2. 點下方的 **分享按鈕**（方框加向上箭頭）。
3. 往下滑，點 **「加入主畫面」**，按「新增」。
4. 主畫面會出現綠色葉子圖示「輕盈日記」，點開就是全螢幕 App，沒有網址列，沒網路也能用。

### 小提醒

- 資料存在這支 iPhone 的 Safari 裡。換手機前請到「⚙️ 設定 → 匯出備份」。
- iOS 可能清除長期沒打開的網頁 App 資料，建議**每週匯出一次備份**（可存到「檔案」或 iCloud Drive）。
- 想像 Apple Watch 一樣快速記錄：把 App 圖示放在主畫面第一頁或 Dock，打開就是「今日」頁，斷食倒數和喝水按鈕都在上面。

## 使用方式

```bash
npm start        # 啟動本機伺服器，打開 http://localhost:8080
npm test         # 執行單元測試
```

也可以把整個資料夾直接部署到 GitHub Pages、Netlify 等靜態網站空間。

## 專案結構

```
index.html        頁面骨架與分頁
css/styles.css    樣式（支援深色模式、手機版面）
js/calc.js        BMR/TDEE/BMI、咖啡因、訓練負荷、進食窗口等純計算函式
js/data.js        食物、運動、咖啡因、徒手訓練、斷食方案資料
js/ai.js          拍照估算的提示詞產生與 AI 回覆解析（不連網路）
js/workout.js     居家訓練計時器
js/app.js         畫面渲染、互動與 localStorage 儲存
sw.js             離線快取
test/             單元測試
```
